# Learn old-school 3D shooters

An interactive, step-by-step series that rebuilds a Wolfenstein 3D–style raycaster
from the maths up, in plain JavaScript that runs directly in the browser.

## Backstory

I wanted to build a Wolfenstein-style 3D engine back in school (6th or 7th grade), but I
didn't have the maths for it yet (no trigonometry), and I never got to think the idea through
end to end afterwards. The closest I came was a second-year university course with labs
that drew graphs directly to video memory.

This repo is that idea, finally built end to end, by Claude (an AI). I watched it build the
series step by step, asked questions until each step clicked, and learned the maths along the
way. It's a teacher and study buddy: competent, patient, and available 24/7. What a great time
to learn new things!

**Start here:** open [`index.html`](index.html) in a browser. No server or build step
needed. If you prefer a local server: `python3 -m http.server` and visit
<http://localhost:8000>.

## Layout

```
index.html            table of contents
PLAN.md               the full plan (Parts 1–4) and conventions
common/style.css      page styling
common/diagram.js     scaffolding for demos: canvas, drawing, mouse, keyboard
steps/NN-name/        one page per step
  index.html          the article with embedded demos
  demo.js             wires the demos on that page
  raycaster.js        the engine as of this step (from step 5 on)
  textures.js         procedural textures (from step 9 on)
  sprites.js          procedural sprites: objects, the robot, pickups, the weapon (from step 11 on)
  game.js             robots, shooting, pickups: the game on top of the engine (from step 13 on)
  hud.js, audio.js    status bar, pixel font, automap; synthesized sound effects (step 14)
```

Every texture, sprite, letter of the font and sound effect is generated by code at startup:
the repo has no image or sound files.

To see what a step adds to the engine:

```sh
diff steps/08-movement/raycaster.js steps/09-wall-textures/raycaster.js
```
